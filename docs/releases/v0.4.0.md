# tuiweave v0.4.0 — release preparation

Status: prepared for review; no tag or public release has been created.

## Proposed release notes

Requires **Go 1.26.7 or newer**. Upgrade the Go toolchain before adopting
v0.4.0. Public tuiweave APIs are unchanged; earlier tags retain their original
requirements.

- Accept bracketed paste in focused text inputs, textareas, and visible command
  palettes. Normalize line endings and remove terminal escapes and unsupported
  controls. Paste never submits or activates commands.
- Preserve textarea newlines and tabs, replace selections in one undoable edit,
  and keep tab rendering, wrapping, selection, and cursor geometry consistent.
- Refresh reference-app filters, completion queries, and layout after paste,
  while preserving focus and modal isolation.
- Adopt Lip Gloss v2.1.0, retaining upstream writer batching and wrap-buffer
  sizing improvements. Historical performance evidence and remaining work are
  recorded in the writer experiment; no new benchmark claims are made here.
- Upgrade Bubble Tea to v2.1.1 to fix denial of service from implausible
  terminal-size reports supplied through untrusted terminal input. This is
  particularly relevant to remote, shared-process terminal services. See
  [GHSA-qc58-pfg9-7pph](https://github.com/charmbracelet/bubbletea/security/advisories/GHSA-qc58-pfg9-7pph).
- Derive the minimum-Go CI job from `go.mod`, disable automatic toolchain
  switching for test jobs, and keep the required minimum check name stable.

## Application migration

Forward `tea.PasteMsg` alongside key messages to the focused input or visible
palette. Reassign the returned model and collect the command. Refresh filters,
completion queries, and layout after pasted edits. Route input to the top modal
and keep hidden controls blurred. See the component README contracts and
`examples/browser`, `examples/chat`, and the completion examples.

Single-line inputs replace pasted LF/tab with spaces; textarea keeps logical
LF/tab. Each textarea tab occupies four cells, or fills a narrower row, while
logical positions count one rune. Programmatic setters keep their behavior.

After publication, install the explicit tag:

```sh
go get github.com/ishan5ain/tuiweave@v0.4.0
```

(The comparison becomes available when the tag is published.)
